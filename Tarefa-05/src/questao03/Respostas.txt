Questão 3 - Modificadores public, protected e private na classe Ponto3D

Trocamos o modificador dos métodos da classe Ponto3D e, para cada caso,
compilamos e rodamos a classe TestePonto3D, que chama esses métodos.

public: compilou e rodou normalmente.

protected: com TestePonto3D no mesmo pacote de Ponto3D, compilou e rodou
normalmente. Quando colocamos TestePonto3D em outro pacote deu erro de
compilação: "imprime() has protected access in Ponto3D". Isso acontece porque
protected só libera o acesso para classes do mesmo pacote e para subclasses,
e TestePonto3D não é subclasse de Ponto3D.

private: deu erro de compilação: "imprime() has private access in Ponto3D"
(e o mesmo para os outros métodos). Um método private só pode ser usado dentro
da própria classe, então nenhuma outra classe consegue chamá-lo.

Não teve erro de execução, só de compilação. Quando não compila, o programa
nem chega a rodar.

Por isso deixamos os métodos como public e só os atributos como private.
